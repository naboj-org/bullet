# Exporting teams

Venue, country and branch administrators can export team data as CSV, JSON or YAML. Operators cannot export teams.

## Downloading an export

1. Select the correct competition.
2. Open "Teams" and click "Export".
3. Choose the country, venue and status filters on the export form.
4. Select an export format and submit the form.

The export form uses the same country, venue and status filters as the team list. Set the filters on the export form itself; do not assume it carries over your current list selection or search.

Use CSV to work with the data in a spreadsheet. JSON and YAML are useful for scripts and other tools that need structured records.

## Handling the file

Exports contain team and contestant details, including contact information. Share them only with people who need that data for the competition, and follow your local rules for storing and deleting personal data.

An export is a snapshot. Download a new copy if teams have registered, changed details or checked in since the previous export.

For a printable check-in list rather than a data export, open the venue's "Team list PDF" tab. That PDF includes competing teams with assigned numbers.

See [managing teams](/admin/documentation/teams/) for the team list and editing.
