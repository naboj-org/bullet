# Certificate generation

After the competition ends, venue, country and branch administrators can generate certificates from the venue's "Certificates" tab.

Complete the [team and venue review](/admin/documentation/review/) first, resolve any result corrections, and check contestant names before printing. Certificates with rankings should use the final results.

## Generating certificates

1. Open "Venues" and select your venue.
2. Open "Certificates".
3. Select either a certificate template or a "TeX Template", not both.
4. Set "Count" to the number of leading teams you want certificates for. The default is 3; enter 0 to include all competing teams.
5. Submit the form.

A regular certificate template returns a PDF directly. Depending on the template, it produces one certificate per team or one per contestant.

A TeX template creates a document-generation job and opens its detail page. Use a "Multiple teams" template for this workflow. See [TeX document generation](/admin/documentation/tex/) for template setup and available team data.

## Blank certificates and printing

With a regular certificate template, select "Empty" to generate blank certificates for filling in by hand. Set a positive count for the number of blank team sets you need. TeX templates do not support the "Empty" option.

Inspect the generated PDF before printing the full batch. Check names, venue, category and rankings, then print a sample to check the layout. If you correct team details or results afterwards, regenerate the affected certificates.

If no suitable template appears, ask the organiser responsible for templates to prepare one for your competition branch or, for TeX, the selected competition.
